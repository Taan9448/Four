# 「결」 설계 문서

「천외귀환」과 같은 저장소의 두 번째 게임(2026-11-09 시작). 「천외귀환」의 그림·데이터·연출 코드를 그대로 가져다 쓰는 **결 읽기 패링 액션**이다.

## 1. 한 줄

하운이 장작의 결을 읽듯 적 공격의 결을 읽고 받아친다. 운해귀종의 "되돌아오는 틈"이 그대로 반격 판정이 된다.

## 2. 왜 같은 저장소의 폴더인가

- 적 70종의 대기·공격·피격 그림과 `meta.json`(타격 프레임 `events.hit`), 이펙트, 반신 그림, 배경이 `assets/` 하나에 있다. Codex가 그림을 고치면 두 게임에 같이 들어간다.
- 적 이름·설정은 `data/enemies/`를, 그림 불러오기·효과음은 `src/render/`를 그대로 쓴다. 「천외귀환」 코드는 고치지 않고 가져다 쓰기만 한다.
- 빌드 한 번에 두 페이지가 나온다(`index.html`, `gyeol/index.html` → 배포 `…/gyeol/`).

## 3. 핵심 흐름(손맛 시제품)

| 순간 | 일 | 수치(`gyeol/data/duel.json` `rules`) |
|---|---|---|
| 적이 공격 자세에 들어감 | 타격 순간 H가 정해진다(그 공격의 `windup` 뒤) | 공격마다 windup·recover |
| H 직전 | **결**이 보인다: 적 → 하운으로 가는 빛줄기와, 과녁 고리로 좁혀 드는 고리. 두 고리가 겹칠 때가 H, 패링 구간에 들면 금빛 | `cueLead` 520 |
| H 전 `perfect` ms 안에 받기 | **패링**: 피해 없음, 적 체간 +(공격 체간 × 1.6), **되돌아오는 틈**이 열린다 | `perfect` 150, `parryPostureMul` 1.6 |
| 그보다 이르게(`guard` 안) 받기 | **막기**: 피해의 1/4, 내 체간 +22. 내 체간이 차면 자세가 무너져 잠깐 무방비 | `guard` 420, `guardChip`, `guardPosture`, `playerStagger` |
| 누르지 않음 / 너무 이름 | 그대로 맞는다. 베던 중이면 베기가 끊긴다 | `hurtLock` |
| 틈 안에서 베기 | **반격**: 피해 3배, 적 체간 +18. 적 몸에 금빛 금이 보이는 동안 | `counterWindow` 700, `counterMul` 3 |
| 적 체간이 가득 참 | **비틀거림**: 그동안 베면 **결정타**(최대 체력의 45%). 놓치면 체간 절반으로 되찾는다 | `stagger` 1600, `deathblow` 0.45 |

- 받기 연타는 막는다(`parryLockout` 220): 아무 때나 누르면 맞는다.
- 적은 공격 중 베여도 멈추지 않는다 — 틈 밖에서 섣불리 베면 맞받는다.
- 적의 공격 순서(`patterns`)가 곧 박자다. 같은 공격도 windup을 달리하면 리듬이 달라진다(이그니스 "불길의 손" 세 번은 점점 빨라짐).

## 3-1. 목업 2차(2026-11-09 사용자 요청 — 확장 전에 목업 완성도부터)

| 기능 | 규칙 | 화면 |
|---|---|---|

- 상대 다섯: 그림자늑대(무속성) · 사슬 감독관(화염) · 얼음 기사(냉기, 아르덴) · 그림자 암살자(번개, 노크투르나) · 화염군주 이그니스(화염 보스). 다섯 모두 속임수·받을 수 없는 공격·악보(14~18박)가 있다.
- 조작에 피하기 추가: L·Shift·가운데 버튼. `?foe=<id>&rhythm`으로 박자 도전 바로 시작, `?debug`는 점검 도구용.
- Codex 그림(받기·피하기 동작, 결 12프레임, 결정타, 기운 3단계, 아이콘 9종)은 **실제 그림이 왔을 때만** 쓰고, 오기 전에는 코드로 그린 대체 연출을 쓴다(임시 상자 그림은 쓰지 않는다).

## 3-3. 진하운의 기술·캐릭터 크기(2026-11-09 사용자 요청)

**결 연환**: 받기·막기·피하기에 끊기지 않고 성공한 수(EXCELLENT·GREAT·GOOD 모두 잇는다, 맞으면 끊긴다). 조건을 채우면 기술이 준비되고 `I`·기술 버튼으로 원할 때 쓴다. 준비된 기술은 맞아도 남는다. 박자 도전에는 없다.

| 기술 | 조건 | 효과(`duel.json` techs) | 원작 |
|---|---|---|---|
| 낙운무흔(落雲無痕) | EXCELLENT 이상 5연환(2026-11-10 상향) | 적 체간 +45%, 피해 6% | 청운십팔식 제십오식 — 장력을 흘려보내자 상대의 균형이 무너졌다 |
| 벽운단하(劈雲斷河) | 5연환 모두 PERFECT(2026-11-10 상향) | 피해 22% + 체간 +35% | 운하검 제일식 |
| 운해귀종(雲海歸宗) | EXCELLENT 이상 10연환(2026-11-10 상향) | 체간 가득(곧바로 비틀거림 → 결정타 기회) + 피해 10% + 받아낸 열 공격 피해 합 × 0.75를 돌려보냄 | "베는 초식이 아니다. 돌려보내는 초식이다." |

- 쓰는 동안(900ms) 무적, 420ms에 터지며 적의 공격을 끊는다. 화면: 0.7초 컷인(기술 일러스트 또는 하운 반신 그림 + 한자 이름 + 대사) → 기술 연출(Codex `fx_gyeol_tech_<id>_a·b` 12프레임, 없으면 코드 연출).
- 조건(2026-11-09 사용자 조정): 같은 연환 수면 EXCELLENT만 이은 쪽(벽운단하)이 앞선다. 더 높은 기술이 열리면 준비된 기술을 바꾼다. 운해귀종은 열 번을 이어야 해서 돌려보내는 배율을 1.5 → 0.75로 낮춰 보스를 한 방에 끝내지 않게 했다(결정타는 남긴다).
- 화면에 결 연환 구슬 열(5·10번째 금테, 모두 EXCELLENT면 금빛, 섞이면 은빛), 준비되면 하운 발밑 기술 색 고리(Codex `fx_gyeol_tech_ready`)와 빛나는 기술 버튼.
- 다음 후보: 10연환 EXCELLENT → 천외귀운(天外歸雲, 운하검 최종식).

**캐릭터 크기**: `foes[].scale`·`player.scale` — 그림자늑대 0.85 · 그림자 암살자 0.95 · 얼음 기사 1.05 · 사슬 감독관 1.12 · 이그니스 1.45, 하운 1.0. 결의 출발점·「危」·틈의 금도 크기를 따른다.

## 4. 그림 재생 규칙(「천외귀환」 규칙 4의 「결」판)

- 그림은 `meta.json`의 프레임 수와 `events.hit`을 따른다. 다만 판정과 그림이 1ms 단위로 맞아야 해서, `SpritePlayer`의 자체 시계 대신 **대결 시계(d.t)로 프레임을 고른다**(`gyeol/src/render.ts`).
- 공격 그림: 1 ~ (hit−1) 프레임을 windup에, hit ~ 끝 프레임을 recover에 펼친다. 그래서 4~6프레임 그림으로도 길게 끄는 공격·빠른 공격을 같은 그림으로 만든다.
- 「천외귀환」 화면 쪽은 여전히 `SpritePlayer`를 쓴다.


### 7-2. 스토리라인 — 운곡루 회상 구조(확정)

### 7-2-1. 서장 — 튜토리얼(2026-11-09 사용자 요청: "서장은 튜토리얼 같은 느낌으로")

### 7-4. 화면 최적화

**재 본 값(2026-11-09, 데스크톱 크로미움 헤드리스, 1280×800, 위기·집중·기술 준비·연속 박자 12를 켠 무거운 순간 240프레임)**

| 조건 | 평균 | 중간값 | 상위 5% | 최대 |
|---|---|---|---|---|
| CPU 그대로 · 이그니스(불티) | 16.9ms | 16.7 | 16.8 | 83(첫 그림 디코딩) |
| CPU 그대로 · 그림자 암살자(비) | 16.6 | 16.7 | 16.7 | 16.8 |
| CPU ×4 느리게(휴대폰 흉내) · 이그니스 | 20.2 | 16.7 | **33.4** | 50 |
| CPU ×4 느리게 · 그림자 암살자 | 21.4 | 16.7 | **49.9** | 67 |

- 데스크톱은 60fps를 지킨다. **느린 기기에서는 무거운 순간마다 프레임이 2~3장씩 빠진다** — 받기 판정이 프레임에 묶여 있지 않아(대결 시계는 실제 시간) 판정은 그대로지만, 고리가 끊겨 보여 손맛이 떨어진다.
- 내려받기: 「결」 첫 화면은 `gyeol-*.js` 77KB + 함께 쓰는 덩어리 811KB(그림 목록 656종·악보·효과음 합성) + 상대마다 그림.

**고칠 것(효과 큰 순서)**

1. **입력 시각 보정**: 지금은 다음 프레임에 `press`가 들어가 최대 16ms(느린 기기 33~50ms) 늦게 판정한다. 키·버튼 이벤트의 `timeStamp`로 "실제로 누른 대결 시각"을 계산해 넘긴다(느린 화면·멈칫 중이면 그 배율로 환산). 받기 게임에서 가장 중요한 최적화.
2. **매 프레임 다시 만드는 것 없애기**: `shadowBlur` 글자(판정·연속 박자·띠), 원형 그라데이션(반딧불·위기 가장자리·집중·연꽃), 색 입히기(`tinted` — 그릴 때마다 작은 캔버스에 복사)를 처음 한 번 그려 캐시한다(글자·색·크기별).
3. **품질 단계 자동 조절**: 최근 1초 평균 프레임이 20ms를 넘으면 한 단계 내린다 — 높음(지금) → 보통(날씨 입자 절반, 글자 빛 번짐 없음, 불꽃 수 절반) → 낮음(날씨 끔, 흔들림 절반). 설정에서 고정할 수도 있다.
4. **로딩 화면**: 지금은 상대 그림을 받는 동안 화면이 비어 있다. 장면·대결 들어가기 전에 다음 상대 그림을 미리 받고, 짧은 먹 번짐 로딩을 보인다.
5. **선명도**: 캔버스가 960×540 고정이라 고해상도 화면에서 글자가 흐리다. 품질 '높음'에서만 `devicePixelRatio`(최대 2)배 캔버스에 그린다(픽셀 그림은 그대로 정수배).
6. **휴대폰 배치**
   - 세로: 지금처럼 화면 위, 버튼 아래(두 줄씩).
   - **가로(권장)**: 화면을 꽉 채우고 버튼을 양쪽 엄지 자리에 겹친다 — 왼쪽 피하기·받기(큰 원), 오른쪽 베기·기술·집중. 세로로 들면 "가로로 돌리면 더 크게" 안내.
   - 전체 화면 버튼, 대결 중 화면 꺼짐 막기(Wake Lock), 두 손가락 확대·길게 눌러 선택 막기.
7. **내려받기 줄이기**: 함께 쓰는 덩어리 811KB를 나눠 본다(무엇이 큰지 먼저 잰다). 「천외귀환」 코드를 고치지 않는 범위에서, 「결」 전용 그림 목록만 담은 가벼운 불러오기를 둘지 정한다.
8. **설정**: 소리(배경·효과), 화면 흔들림 크기, 번쩍임 줄이기(광과민), 판정 보정(±ms, 수련장에서 잼), 글자 크기, 키 바꾸기, 품질.
9. **점검 도구**: `npm run perf:check`처럼 「결」에도 프레임·메모리 점검(무거운 순간 재현은 `?debug`로)과 화면 점검(PC·휴대폰 세로·가로)을 붙인다.

**1단계 결과(2026-11-09)**

- 입력 시각 보정: 버튼·키의 `event.timeStamp − 판정 보정`까지 대결 시계를 먼저 민 뒤 누른다. 화면이 이미 앞서 있으면 그만큼 거슬러 올라간 시각으로 받기·피하기를 판정한다(`press(d, input, at)`, 최대 `MAX_INPUT_LAG` 80ms).

- 저장(`gyeol/src/save.ts` — `gyeol.save` v1, 옛 `gyeol.rhythmBest`를 옮김), 설정 창(소리 셋·흔들림·번쩍임 줄이기·판정 보정·품질).
- 로딩 화면, 전체 화면 버튼, 대결 중 화면 꺼짐 막기, 휴대폰 가로 배치(왼손 받기·피하기, 오른손 베기·기술·집중), 세로일 때 가로로 돌리라는 안내.
- 점검: `npm run gyeol:perf`. 다시 잰 값(CPU ×4): 상위 5% 50 → 33ms, 최대 67 → 33~50ms. **품질 low로 낮춰도 33ms는 그대로**라, 남은 몫은 헤드리스 크로미움의 소프트웨어 그리기·화면 합성(우리 스크립트는 프레임의 약 10%)이다 — 실제 휴대폰(GPU)에서 다시 재 본다.
- 내려받기: 「결」 진입 85KB + 함께 쓰는 덩어리 811KB는 그대로다. 「천외귀환」 코드를 고치지 않는 범위에서 나누는 일은 2단계 이후에 본다.

**판정 4단계·기술·겨루기 조정(2026-11-10 사용자 요청 "Perfect 기준 추가, 베기 대결이 너무 쉽다, 기술 발동 조건 상향")**

### 7-6. 제목 · 계정 · 로비 그림 · 큰 전투 화면(2026-11-10 사용자 요청)

| 결 가림 `veil` | 집중하지 않으면 결이 그 비율만큼만 보인다(8장 붉은 장력과 같은 장치) | 집중 |

**겨루기 기회 안내(2026-11-11 사용자 요청 — "조건이 많아서 그 상황인지 알기 어렵다")** — 겨루기가 될 수 있는 공격이 오면 미리 보인다(`clashChance`): 결 연환이 `clashMinChain` 이상이고, 무거운 공격(피해 20 이상 또는 `clash`)이며, 붉은 결·반격 자세·왕녀의 얼음·세 숨이 아니고, 겨루기가 켜진 대결이고, 하운이 연타 중이 아닐 때. 적 머리 위 주황 「劍」, 과녁 아래 "겨루기 — 맞부딪힐 때 J" → 타격 직전(겨루기 창 ×2.5)에는 "지금 베기 J!"와 칼빛 고리. 결 연환이 3 이상이면 구슬 아래에 "겨루기 준비". 처음 한 번 안내(`clashReady`, 결투장에서도).

**하운 옷(`gyeol/data/progress.json outfits`)** — 「천외귀환」 하운 옷 그림(`skin_<id>_haun_idle·attack·hit`)을 입힌다. 받기·피하기·기술·겨루기·쓰러짐은 기본 옷 그림. 잡역복(처음) · 청운의 귀환(5장) · 천마를 넘어(9장) · 심연을 걷는 자(10장) · 순례의 끝(에필로그) · 불멸(별 30). 기록 화면에서 고른다(`save.outfit`).

### 7-12. 전투 화면 · 이야기 지도 · 수련장(2026-11-11 사용자 요청)

> "전투 버튼이 작다, 나가기는 빼고 Esc로 멈춤 / 하운 이름·목숨·게이지가 잘 안 보인다, 스펙타클한 애니메이션 / 결과 버튼 디자인·크기 통일 / 이야기는 천외귀환처럼 지도 / 박자 도전은 수련장 안으로 / 決은 처음의 붉은 먹 / 제목 '결 — 손맛 시제품'을 원래 이름으로"

- **일시 정지**: 나가기 버튼을 없앴다. Esc(또는 P, 오른쪽 위 ❚❚)로 멈추고 같은 키로 이어 간다. 멈춘 동안 대결 시계·입력이 서고, 풀면 멈칫·느린 화면 시각을 멈춘 만큼 뒤로 민다. 창 — 계속 · 처음부터 · 나가기(이야기는 「이야기 지도」, 수련은 「그만하기」, 서장은 「서장 건너뛰기」). 다른 탭·창으로 가면 저절로 멈춘다. 결과가 떠 있을 때 Esc = 나가기.
- **버튼**: 다섯(베기·피하기·받기·기술·집중)을 한 줄에 크게(PC 84px 높이, 글자 26px).
- **하운 이름판**: 얼굴 인장(결 전용 반신 그림, 없으면 「천외귀환」 반신) + 이름 + 체력 숫자, 굵은 체력 막대(16px), 이름 붙은 체간·집중 막대. 적 체력 막대에도 숫자.
- **막대 연출**: 윤기 빛줄기가 천천히 훑는다 · 맞으면 막대가 흔들리며 하얗게 번쩍(12% 넘게 깎이면 더 세게)하고 이름판이 흔들린다 · 깎인 만큼 밝은 잔상이 0.4초 남았다 따라 줄어든다 · 차오르면 초록빛 · 30% 아래면 막대와 이름판·얼굴이 붉게 맥박친다 · 적 체간이 75% 넘으면 금빛이 타오르고(무너뜨릴 때), 내 체간이 75% 넘으면 붉게 깜박인다(무너지기 직전) · 집중이 차면 푸른 불꽃이 한 번 터지고 반짝인다.
- **결과·일시 정지 단추**: 모두 같은 크기(188×58)의 먹 판, 앞에 오는 단추만 붉은 인장 테(◆). 단축키 글자(Enter·Esc)를 단추에 적는다.
- **이야기 지도**: 장 목록 대신 「천외귀환」 여정 띠 그림(`journey_band`) 위에 장마다 인장(序·一~十·終)을 찍고 지나온 길은 붉은 먹, 다음 장으로 가는 길은 흐르는 점선, 남은 길은 옅은 점선. 자리는 `story.json` 장의 `map`(그림 기준 %, 「천외귀환」 스테이지 여정 자리와 같다). 인장을 누르면 아래 쪽지에 장 제목·회상·별·도전·「들어가기」, 한 번 더 누르거나 Enter면 들어간다. ←→로 장을 옮긴다.
- **수련장**: 메인 메뉴에서 박자 도전을 빼고 수련장 안에 칸 둘 — 修 수련(철목인 수련·박자 맞추기) · 拍 박자 도전(악보 목록). 박자 도전을 마치면 수련장 박자 도전 칸으로 돌아온다.
- **決**: 시작 화면·메인 가운데 모두 먹 원(붉은 낙관) 안 밝은 종이 위에 주홍 먹 글씨(메인은 천천히 숨쉬듯 번진다).
