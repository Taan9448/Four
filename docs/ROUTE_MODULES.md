# ROUTE_MODULES — 지도 생성과 모듈

구현: `src/engine/route.ts`(지도), `src/engine/run.ts`(진행·런 단위 동작). 테스트: `tests/route.test.ts`, `tests/run.test.ts`.

## 1. 지도

- 스테이지(`data/stages.json`)의 `floors`만큼 층을 만들고, 맨 위에 보스 층 하나를 더한다.
- 층마다 노드 `route.nodesPerFloor`(기본 2~3)개. 고정 노드가 있는 층은 노드 1개라 모든 경로가 지나간다.
- 연결: 위치가 비슷한 다음 층 노드와 잇고, `extraEdgeChance`(0.35) 확률로 옆 노드에 갈래길을 더한다. 들어오는 길이 없는 노드는 가장 가까운 노드에서 잇는다.
- 노드 유형: `battle`, `elite`, `event`, `rest`, `inn`, `story`(고정), `boss`(고정).
- 유형 선택은 스테이지의 `typeWeights` 가중치. `forcedTypes`로 특정 층을 강제한다(S1: 9층 휴식).

## 2. 생성 제약(테스트로 보장)

- 모든 노드는 1층에서 도달할 수 있고, 모든 노드에서 보스까지 갈 수 있다.
- 고정 노드는 지정한 층에 단독으로 있다.
- `eliteMinFloor`(3층) 이전에는 엘리트가 없다(고정 노드는 예외: S5 1층 그림자의 밤).
- **전투 없는 노드 연속 제한(2026-10-08 S3 리뷰 "5연속 이벤트로 그냥 넘어감"):** 어느 길로 가도 전투 없는 노드(사건·휴식·여관·이야기)가 `maxCalmRun`(2)을 넘어 이어지지 않는다(2026-10-08 S4 리뷰: 고정 이야기도 센다. S5 리뷰 "이벤트가 너무 많다"로 3 → 2). 무작위 노드를 놓을 때 바로 뒤에 고정 이야기·정해진 휴식(보스 앞 등)이 있으면 그것까지 세어 앞쪽을 전투로 당긴다. 고정 노드끼리 붙어 생기는 연속(S9의 이야기 묶음)만 예외. `validateMap`이 검사한다.
- **노드 비율(2026-10-08 S5 리뷰):** 스테이지마다 `typeWeights`를 전투 52~58 · 사건 14~18 · 엘리트 12~15 · 휴식 7~8 · 여관 5~7로 낮췄다(보스 앞 휴식은 정해져 있어 무작위 휴식은 적게). 한 길에서 사건은 평균 0~1번, 전투 없는 노드 비율은 고정 이야기가 많은 S1·S9를 빼면 42~52%(전에는 52~66%).
- 휴식 노드가 연이어 오지 않는다.
- **고르게 섞기(2026-10-25 사용자 요청 — "만든 몬스터가 안 나온다"):** 엘리트는 한 지도에 같은 모듈을 두 번 놓지 않고, 전투는 같은 층의 이웃 노드끼리 다른 모듈로 놓는다(남은 모듈이 없으면 겹쳐도 된다). S0 청운산은 7층(1 장작 · 2 일상 사건·휴식 · 3 등운시 · **4 철목인 고정** · 5 전투 고정(도끼 잡아먹는 놈들·내원 사형들) · 6 관운각 밀담 · 7 쫓기는 숲 사건), S9 세계의 틈은 6층을 엘리트로 고정했다. 한 판에 만날 확률: 철목인 20% → 100%, 뼈 거인 13% → 37%, 그림자 다리 15% → 47%.
- **나올 수 있는가(테스트):** 캠페인 모듈마다 나올 층이 있고(고정·정해진 층·유형 비율·엘리트 최저 층), 시드 300개면 이야기를 뺀 모든 모듈이 지도에 한 번 이상 나온다(전투 없는 노드 연속 한도까지 따진다). 예외: S9 사건·휴식은 자유 층(3·6·9층)이 모두 이야기 둘 뒤라 캠페인에 못 나오고 심연 틈 세계 굽이에서만 나온다.
- `once` 모듈은 런당 1회(지도 안에서도, 이미 쓴 것도).
- 같은 시드 → 같은 지도. `validateMap()`이 이 규칙들을 검사하고, 테스트는 200개 시드로 돌린다.

## 3. 모듈 스키마(`data/modules/<stage>.json`)

```jsonc
{
  "id": "s1_battle_wolf_pack",        // 고유 id
  "stage": "s1",
  "type": "battle",                    // battle | elite | event | rest | inn | story | boss
  "name": "그림자늑대 무리",
  "weight": 2,                         // 같은 유형 안에서의 가중치
  "tags": [],                          // "scar"면 상흔에 비례해 가중치 증가
  "once": false,                       // 런당 1회
  "conditions": {                      // 생성 시점 조건(모두 선택)
    "floorRange": [3, 9],             // 고정 층(pinned)·정해진 상점/휴식 층(forcedTypes)과만 겹치면 영영 안 나온다 — tests/route.test.ts가 막는다
    "scarMin": 0,
    "flag": "met_companions",          // 이전 고정 스토리 노드가 줄 플래그도 인정
    "partyHas": "kyle"                 // 합류(예정) 동료
  },
  "content": {
    "text": "...",
    "enemies": ["shadow_wolf", "shadow_wolf"],          // 전투형
    "choices": [ { "label": "...", "result": "...", "effects": [ /* 런 단위 동작 */ ] } ],  // 이벤트형
    "bonus": { "condition": { "partyHas": "kyle" }, "text": "...", "effects": [ /* 전투 동작 */ ] },
    "surviveTurns": 3,                 // 전투형: 이 턴 수를 버티면 승리(이길 수 없는 전투)
    "riftDecay": 0,                    // 전투형: 차례 끝 균열 감쇠(세계 기본값 balance.rift.decay 대신). 이그니스의 화로 안은 0
    "riftDecayNote": "화로",           // 균열 게이지 주석에 붙는 까닭(짧게)
    "enemyScale": { "hp": 1.25, "dmg": 1.1 }, // 전투형: 이 전투 모든 적의 배율(등급·어려움·순례·심연 배율 뒤에 곱한다, 기본 1). 엘리트·일반 난이도 맞추기
    "outro": "...",                    // 보스형: 스테이지를 마친 뒤 보여 줄 장면 글(outroScene이 있으면 생략)
    "scene": "s0_scene_secret_talk",   // 노드에 들어가면 먼저 재생할 비주얼 노벨 장면(data/scenes)
    "outroScene": "s0_scene_stone_gate", // 전투형: 이긴 뒤 재생할 장면(보스는 스테이지 끝 전, 일반·엘리트는 보상 전)
    "clearEffects": [ /* 런 단위 동작 */ ]  // 전투형: 이기면 런에 적용(예: 천외귀운 영구 획득, 플래그). 보스는 결과가 스테이지 끝 화면에 보인다
  }
}
```

**런 단위 동작**(선택지·휴식·지원 규칙의 `restOption`): `gain_card`(보유 카드에 영구로 + 이번 스테이지 덱, 이미 있으면 강화 — GAME_DESIGN 9-1), `remove_card`(filter: 이번 스테이지 덱에서만 뺀다. 덱을 얇게 하지 않는 원칙이라 지금 데이터는 쓰지 않는다), `upgrade_card`(count, filter: 보유 카드의 강화 단계가 오른다), `heal_party`(amount | ratio), `gain_run_mana`, `scar`, `set_flag`, `join_party`, `leave_party`(빈 출전 자리는 남은 동료로 채운다), `gain_gold`(amount), `gain_max_hp`(amount: 합류한 동료 모두), `gain_relic`(relic: 없으면 가지지 않은 보스 아닌 유물 중 무작위, `rarity`로 등급 제한), `gain_potion`(potion: 빈 칸이 없으면 두고 온다), `gain_random_card`(rarity: 합류한 동료·공용의 보상 카드 중 그 등급, 없는 카드 우선), `swap_card`(choose: 사람이 고른 보유 카드를 같은 주인의 다른 카드로 — 상점의 카드 바꾸기와 같다), `sell_card`(amount, choose: 고른 보유 카드를 보유·편성·덱에서 빼고 골드 amount), `gain_potion_slot`(amount: 물약 칸 늘리기 — 옥가락지), `rescue`(amount: 구출 사건에서 데리고 나온 사람 수를 런에 센다 — 스테이지 끝 화면 '구한 사람 n명', 개작 원고 B안 2026-10-31).

**선택지 필드:** `condition.goldGte`(골드가 모자라면 흐리게 보이고 고를 수 없다), `outcomes: [{ weight, effects, result }]`(확률 결과 — 선택지의 effects를 먼저 일으키고, 노드마다 정해진 시드 수열로 하나를 고른다. 노름판).

**어디서나 나오는 사건(`data/modules/any.json`, `stage: "*"`):** `stages[].templateEvents`가 true인 스테이지(S1~S8) 지도에 그 스테이지의 사건과 함께 섞인다. 한 지도에 한 번씩, 스테이지마다 다시 나올 수 있다(GAME_DESIGN 10-1).

**상점 노드(`shop`, 2026-10-08):** 스테이지마다 정해진 층(`forcedTypes`, S1·S2~S7은 보스 앞 휴식 바로 앞, S8은 5층) 전체가 상점이다(S0·S9는 없음). 모듈은 `content.text`(상인 소개)만 있고 선택지가 없으며, 진열은 `src/engine/economy.ts`가 노드마다 시드로 정해 `run.shop`에 남긴다. 상점·휴식은 두 번 잇따르지 않는다.

**심연 런 동작(GAME_DESIGN 16절, 심연에서만 일한다):** `gain_abyss_card`(열린 틈의 카드 중 희귀 이상 한 장을 덱에), `reveal_unseen_card`(풀에 없는 합류 동료·공용 카드 한 장을 보여 주고 풀·도감에 넣는다 — 얻지는 않는다), `injure`(하운이 아닌 동료 한 명 부상: 다음 굽이까지 최대 체력 −`abyss.injuryRatio`), `cure_injury`(부상을 모두 고친다). `remove_card`에 `choose: true`면 사람이 고른 카드(uid)를 뺀다(심연의 휴식 '버리기'·틈의 거래). 심연에서는 `gain_card`·`gain_random_card`·`swap_card`·`sell_card`·`upgrade_card`가 보유 목록 대신 덱의 카드에 일한다(같은 카드 여러 장 가능, 강화는 그 한 장만). `scar` amount ≤ −99는 '상흔을 모두 지웠다', `gain_gold` amount ≤ −9999는 '골드를 모두 냈다'로 적힌다.

**심연 모듈(`data/modules/abyss.json`, `stage: "abyss"`):** 숙적 보스(`abyss_boss_mordecai`), 사무결의 잔향(무림 보스 후보), 틈의 거래 사건 4개(`tags: ["trade"]`, 한 지도에 하나), 틈의 좌판(상점 — 틈 세계에는 상점이 없어서). 정해진 자리에만 나오는 것(`abyss: false`): 3굽이 4층의 구원·틈의 메아리, 상흔 10마다 5층의 틈의 짐승(clearEffects `gain_abyss_card` — 심연 모듈의 clearEffects는 심연에서도 일어난다). 선택지 조건 `partyLacks`(그 동료가 일행에 없을 때만), `remove_card`의 `count`(여러 장). 심연 지도에는 그 굽이 세계의 스테이지 모듈(`balance.abyss.worlds[세계].stages`)과 어디서나 사건·심연 모듈이 섞인다. 빠지는 것: `abyss: false` 모듈, 이야기(story)·보스 유형, 플래그 조건, 합류하지 않은 동료 조건, 동료 합류·이탈 사건. `floorRange`는 보지 않는다. 장면(scene·outroScene)은 재생하지 않고 보스의 `clearEffects`도 일어나지 않는다. 서약 '막아선 자'(`eliteFloor`)는 그 층을 `forcedTypes`에 엘리트로 더한다. 심연 선택지를 고르면 업적 셈에 "모듈:동작"이 남는다(`trackChoice` — 구원·틈의 메아리 업적).

**스테이지 `endingScene`**(`data/stages.json`): 캠페인의 마지막 스테이지에 둔다. 보스를 넘고 "마치기"를 누르면 이 장면(에필로그)을 재생한 뒤 엔딩 화면("천외귀환 — 완")을 보여 준다.
filter: `{ pool, owner, costNeigongGte }`. 무작위 선택은 `시드 + 스테이지 + 노드 + 순번` 라벨의 RNG로 결정된다.

## 5. 비주얼 노벨 장면(`data/scenes/<stage>.json`)

```jsonc
{
  "id": "s0_scene_cliff",
  "world": "murim",                                  // 배경 톤(murim | elheim | nocturna | rift)
  "lines": [
    { "text": "결국 숲이 끝났다." },                   // 화자 없음 = 내레이션
    { "speaker": "kwak_dojin", "name": "장문인 곽도진", "text": "그 밥값을 오늘 치르거라." },
    { "speaker": "haun", "face": "resolve", "text": "산문의 현판에 쓰신 글은 다 거짓이었습니까." },
    { "cg": "cg_fall", "text": "세상이 기울었다. 하운은 떨어졌다." },       // cg: 이 줄부터 장면 일러스트(story-cg). "none"이면 걷는다
    { "effect": "flash", "text": "세상이 하얗게 타올랐다." },               // effect: flash | shake | fade (이 줄에서 한 번)
    { "if": { "flag": "s2_born_inside", "partyHas": "born" }, "speaker": "born", "text": "화로의 결. 내가 찾는다." }  // if: 플래그·출전 동료가 맞을 때만 보이는 줄(도감 다시 보기에서는 모두 보인다). 조건 없는 줄이 하나는 있어야 한다
  ]
}
```

- `speaker`: 캐릭터(`data/characters.json`) 또는 장면 전용 화자(`data/speakers.json`). 반신 그림 에셋은 `<speaker>_stand`(표정 프레임 1 기본·2 결의·3 놀람)
- `side`: 생략하면 하운은 왼쪽, 나머지는 오른쪽. `name`: 이 줄에서만 쓸 표시 이름(정체를 숨긴 인물 등). `face`: neutral | resolve | surprise
- **표정 규칙:** `face`를 생략하면 그 인물의 직전 표정을 유지한다(장면에 처음 나올 때는 neutral). 기본 표정으로 돌아가려면 `"face": "neutral"`을 적는다. 한 인물의 표정은 바뀐 뒤(또는 처음 나온 뒤) **장면 줄 수로 3줄이 지나야** 다시 바꿀 수 있다(`src/engine/scene.ts` `FACE_HOLD_LINES`, `data:check`가 검사). 감정이 빨리 바뀌어야 하면 대사를 두 줄로 끊거나 내레이션을 한 줄 넣는다. 화면에서는 같은 인물의 표정이 0.45초 동안 교차 페이드로 바뀐다.
- `data:check`가 장면 참조, 화자, 반신 그림 명세를 검사한다.
