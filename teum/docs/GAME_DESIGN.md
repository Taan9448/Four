## 1. 화면 흐름
1. **들어가기(로그인):** 「결」·「천외귀환」과 같은 판 — 로그인·회원가입 탭은 보이되 **지금은 「준비 중」**, 아래 「게스트로 시작」 한 줄. 게스트 기록은 이 브라우저에만.
2. **메인(로비):** 가운데 메뉴 넷 + 오른쪽 아래 둥근 표식.
   - **불러오기** — 저장 3칸 중 하나를 골라 다음 장부터 잇는다(찬 칸이 있을 때만).
   - **저장** — 저장 칸 보기: 어느 칸에 자동 저장할지 고르기·지우기. **손으로 저장하는 단추는 없다**(장을 끝낼 때마다 자동).
   - **스토리** — 새 이야기: 칸 → 난이도(노말 / 하드 「준비 중」) → 인물 → 1장.
   - **무한 모드** — 「준비 중」(스토리를 다 만든 뒤).
   - 오른쪽 아래: **도감**(만난 그림자·무공·심법) · **옷장**(인물·옷) · **옵션**(흔들림·피해 숫자·지도 크기·기록 지우기) / **천외귀환** · **결** 바로가기.
3. **장 시작:** 장 일러스트 카드(이름·한 줄) → 판. **장 끝:** 보스를 쓰러뜨리면 「n장을 넘었다」 → 자동 저장 → 다음 장 / 메인으로.

## 4. 지형(`src/terrain.ts`)
- 장마다 **가둔 판**(약 100×100칸, 한 칸 40px ≈ 4000px). 판 밖으로는 못 나간다. 시드로 같은 판이 나온다.
- 칸 종류: **바닥** · **벽**(나무·바위·집·담 — 막는다, 적 탄도 막는다) · **위험**(용암·물·허공 — 걷는 것은 못 들어간다, 탄은 지나간다) · **느림**(덤불·눈·핏물 — 0.6배) · **다리**(위험 위의 바닥).
- 지형 짓기(데이터로 고른다): `blobs`(나무·바위 덩어리) · `river`(구불구불한 강과 다리) · `bands`(가로 단과 좁은 계단) · `rooms`(방·담·문) · `caves`(굴) · `islands`(허공 위 섬과 다리) · `slow`(느린 땅 얼룩). 짓고 나면 **모든 바닥이 이어지게** 끊긴 곳을 뚫는다.
- 적 길찾기: 인물이 있는 칸에서 퍼지는 **흐름장**(0.25초마다 BFS) — 걷는 적은 벽을 돌아온다. **나는 적**(박쥐·정령·환영 등 `fly`)은 지형을 넘는다.
- 오른쪽 위 **지도**: 지형을 줄여 그리고 인물·그림자·보스·상자·물건을 점으로.

## 5. 조작
- 움직임만 직접(WASD·방향키 / 휴대폰은 화면 왼쪽을 끌어 가상 막대). 무공은 저절로.
- **보법**(Space·Shift): 짧게 미끄러지며 무적, 스치면 「간파」. **천외귀운**(Q): 균열 게이지가 차면 인물의 마지막 기술.
- **ESC**: 멈춤(계속 · 옵션 · 메인으로 — 장 처음부터 다시 해야 한다고 알림).

## 6. 성장 — 장을 넘어도 이어진다
- 레벨·경험·무공·심법·최대 체력·금화를 장 끝에 저장하고 다음 장으로 가져간다. 장을 시작할 때 체력은 가득.
- 레벨업 카드 셋(새 무공 · 무공 +1 · 심법 +1), 무공 6칸 · 심법 6칸, Lv.5 + 짝 심법 + 상자 = **각성**(5종).
- 다 찬 뒤에는 「체력 +10」·「금화」 카드.

## 8. 그림자의 공격 패턴(`data/foes.json moves`) — 장마다 새로

## 12. 숫자 맞추기
- 엔진(`src/sim.ts`)·지형(`src/terrain.ts`)은 순수 함수 + 시드 RNG. 수치는 `data/*.json`.
- 봇(`tests/bot.ts`): 지형을 피해 원을 그리며 싸우고 첫·잘 고른 카드를 고른다. **잘 고르는 봇이 노말 1~4장을 넘고, 장이 갈수록 힘들어지게**(뒤 장은 사람 손을 기준으로 다시 맞춘다).
- 그림자는 동시에 350 이하.
- **무한 모드**(나중): 1차 30분 판(`run.json`)을 바탕으로 지형 판을 이어 붙인다.
